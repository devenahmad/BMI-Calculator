BMI Calculator

A BMI calculator I built while practicing HTML, CSS, and JavaScript. Enter your weight and height, choose between Metric or Imperial units, and get your BMI and category instantly.

Live Demo

https://bmi-calculator-by-deven.vercel.app/

Features
Metric and Imperial unit support
Weight and height validation with helpful error messages
BMI calculation with category detection
Animated semi-circle gauge based on BMI value
Gauge color changes according to BMI category
Active category highlighted in the BMI legend
Light and dark theme switcher
Dark theme preference saved with localStorage
Responsive layout for desktop and mobile
Accessible form with ARIA attributes and live result updates
Technologies Used
HTML
CSS
JavaScript (no frameworks, just vanilla JS)
How It Works

Choose a unit system and enter your weight and height. The calculator validates the values first, then converts them when needed and calculates BMI using the appropriate formula.

The result updates the BMI value, category, gauge position, gauge color, and active legend item. The theme switcher also remembers your selected theme using localStorage.
